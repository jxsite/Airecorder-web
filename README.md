# AIRecorder AI 

[English](#english) | [简体中文](#chinese)

<a name="english"></a>
## English

AIRecorder is a professional AI-powered voice recording and transcription application. It captures your thoughts and automatically converts them into beautifully structured notes.

### 🌟 Key Features
- **AI Structured Notes**: Automatically converts voice to organized Markdown notes using Gemini Pro.
- **Multi-Style Transformation**: Choose from Summary, List, Journal, or Email styles.
- **Multi-Language Support**: Supports transcription and translation in 20+ languages.
- **Audio Import**: Import existing MP3/M4A/WAV files for AI summarization.
- **Privacy First**: Support for private VPS server configuration for data sovereignty.
- **Premium Features**: Unlimited storage, longer recordings, and "SuperSummary" note merging.

### 🚀 Getting Started
1. **Download the APK**: You can find the latest debug build in the [Releases](https://github.com/jxsite/Airecorder/releases/tag/Airecorder) (or the `app-debug.apk` in the root).
2. **API Key**: Ensure you have a Gemini API key configured in the `BuildConfig`.
3. **Login**: Register or login to sync your data with the cloud.

<a name="chinese"></a>
## 简体中文

AIRecorder 是一款专业的 AI 智能语音记录仪。它可以捕捉您的灵感，并利用 AI 自动将其转化为结构清晰、重点突出的笔记。

### 🌟 核心功能
- **AI 结构化笔记**：使用 Gemini Pro 自动将语音转录为整理有序的 Markdown 笔记。
- **多风格重塑**：支持摘要、清单、日记、邮件等多种笔记风格切换。
- **多语言支持**：支持 20 多种语言的转录与互译。
- **音频导入**：支持导入 MP3/M4A/WAV 文件进行 AI 提炼。
- **隐私保护**：支持私有 VPS 服务器配置，确保数据主权。
- **高级特权**：无限存储空间、超长录音支持及“超级摘要”笔记合并功能。

### 🚀 快速开始
1. **下载安装包**：您可以在 [Releases](https://github.com/jxsite/Airecorder/releases/tag/Airecorder) 中找到最新的 APK 安装包（或根目录下的 `app-debug.apk`）。
2. **API 密钥**：确保在 `BuildConfig` 中配置了 Gemini API 密钥。
3. **登录账号**：注册或登录以同步您的云端数据。

### 🛠 Tech Stack / 技术栈
- **Language**: Kotlin
- **UI Framework**: Jetpack Compose
- **Database**: Room
- **Networking**: Retrofit + OkHttp
- **AI Engine**: Google Gemini Pro
- **Architecture**: MVVM
